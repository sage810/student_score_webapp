# AGENTS_MAP — student score webapp

이 프로젝트에서 어떤 스킬·에이전트가 관여했는지만 적는다. 그 스킬이 뭘 해줬는지 결과(색·구조 등)는 여기 적지 않는다 — 그건 `.design/style-lock.md` 몫이다. 새 스킬을 쓰기로 결정한 순간 바로 한 줄 추가한다.

## 사용 중

| 스킬/에이전트 | 역할 | 상태 |
|---|---|---|
| design-system | 전체 디자인 워크플로우 진행 | 항상 사용 |
| project-housekeeping | 작업 마무리 시 지도 문서 정리 | 작업 완료 신호 때 사용 |

## 이번 프로젝트에서 추천받았지만 쓰지 않은 것

| 스킬 | 왜 안 썼는지 |
|---|---|
| web-design-guidelines | 품질 점검 후 사용 여부를 물었으나 답이 없어 쓰지 않음. 대비·터치 크기·label은 직접 점검함 |
