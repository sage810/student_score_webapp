# Style Lock — student score webapp

이 파일이 있으면 3단계(톤·색·타이포 도출)를 다시 하지 않고 아래 값을 그대로 재사용한다. 방향을 바꾸고 싶다는 명시적 요청이 있을 때만 갱신한다.

## 배포 방식

- 방식: Google Apps Script HtmlService (Google Sheets 바인딩 스크립트)
- 확인일: 2026-09-18

## 목적·사용자

- 목적: 학생용 수행평가 결과 조회(1회성) + 교사용 담당범위/영역/반별 점수 관리(반복 사용)
- 정보 밀도: 학생 화면 낮음 / 교사 화면 중간~높음
- 격식/친근함: 중간 (학교 공식 도구이지만 학생 화면은 친근한 카드형)
- 사용 빈도: 학생=1회성(콘텐츠형), 교사=반복 사용(도구형)

## 색상

| 역할 | 값 | 비고 |
|---|---|---|
| 배경 | `#f7f7fb` | 순백 대신 은은한 오프화이트 |
| 텍스트 | `#101114` (본문) / `#686b82` (보조) | Kraken Near Black + Cool Gray |
| 포인트(강조) | `#7132f5` (Kraken Purple) / hover `#5741d8` | 버튼·배지·강조 카드 |
| 보더/구분선 | `#dedee5` | |
| 완료 표시 | `#149e61` (그린, 현재 배지류에 예약) | |
| 에러 | `#c62f42` | 기본 Kraken 팔레트에 없어 대비 기준(4.5:1) 통과하도록 별도 산정 |
| 미실시/예정(비활성) | 배경 `#f7f7fb` + 텍스트 `#686b82` | opacity 대신 배경·색 분리로 대비 기준 유지 |

## 타이포

- 본문/제목 폰트: Pretendard (CDN, 한글 최적화 — Kraken 자체 폰트 대체)
- 기본 크기: 본문 14~15px, 학생 화면 타이틀 22px, 결과 총점 34px
- 최소 글자 크기: 12px (배지·열 제목·라벨 포함)

## 간격·터치 기준

- 간격(padding/margin/gap): 4px 배수만 사용 (2px 반 단계는 허용)
- 터치 영역: 버튼·탭은 44px 이상, 결시 체크박스와 반 칩의 × 버튼은 24px 이상
- 안내 문구(placeholder) 색: `#727589` (`--ink-faint`, 대비 4.5:1 이상)
- 확대(줌) 허용: viewport에 `maximum-scale` 넣지 않음
- 입력칸은 label 또는 `aria-label`을 반드시 연결
- 경고 표시는 이모지 대신 SVG 아이콘 사용

## 레이아웃 구조

- 선택한 틀: 학생 화면 = 가운데 정렬 단일 카드(모바일 우선, JS로 화면1↔2 전환) / 교사 화면 = 다크 헤더 + 단계형(1~3) 카드 스택 + 하단 고정 안내바
- 교사 화면 메뉴: 홈 화면에서는 상단 바 안의 메뉴(홈~엑셀 파일 다운로드, 1280px 이하는 3열×3행 격자). 섹션 화면에서는 상단 메뉴를 숨기고 좌측 고정 사이드바로 대신함. 사이드바는 넓은 화면에서 흰 배경 248px에 메뉴 이름만 나열(홈 아래 구분선 하나, 선택 항목은 보라 틴트 배경), 1280px 이하는 왼쪽에 떠 있는 164px 도크(흰 카드·20px 모서리, 18px 아이콘 옆에 13px 메뉴 이름, 상단 바 아래 영역의 세로 가운데에 고정해 스크롤 없음, 선택 항목은 보라 배경). 두 경우 모두 선택되지 않은 메뉴는 흐린 글자색(#727589, 대비 4.5:1 유지 — opacity 사용 안 함), 마우스를 올리면 진하게. 본문은 손잡이와 12px 이상 떨어지도록 비키되(닫힌 상태 포함) 640px 이하 휴대폰 폭에서는 비키지 않고 도크가 위에 뜸. 여닫기는 사이드바·도크 오른쪽 가장자리에 붙은 손잡이 탭(보이는 크기 24×56px, 누르는 영역 44px, 닫히면 화면 왼쪽 끝에 남음)
- 선택 이유: 학생은 1회성 폼 입력이라 카드 하나에 집중, 교사는 반복 작업이라 순서가 있는 대시보드 형태가 더 적합
- 화면2(결과) 상세: 상단은 "학기·과목" 알약 배지 + "학급·이름" 카드를 위아래로 분리, 둘 다 텍스트 길이에 맞춰 폭이 줄어드는 가운데 정렬(내용물 hug). 점수 영역은 표 형식(열 제목: 영역/나의 점수/만점, 열 사이 세로 구분선)이고, 그룹 있는 영역은 그룹명을 보라색 소제목으로 표시. 영역마다 4가지 상태를 구분: 완료(점수/만점 숫자), 이번 수행(보라 왼쪽 강조 바 + 배경 틴트 + "이번 수행" 배지, 점수칸은 "-"·만점은 그대로 표시 — 설정 시트 "현재영역" 값과 일치하는 영역), 미실시(연한 배경 + 이탤릭 + ink-soft, "미실시" 텍스트 — 실시했어야 하는데 안 한 경우), 예정(연한 배경 + "예정" 텍스트를 보라 톤으로, 이탤릭 아님 — 아직 학급 전체가 도달하지 않은 경우). 미실시/예정 모두 opacity로 흐리게 하지 않고 별도 배경(--bg)과 명시적 텍스트 색으로 처리(대비 기준 4.5:1 유지 목적). 총점은 완료된 것만 합산한 "받은점수 / 응시분 만점"(예: 33/36) 형태로 하단 그라디언트 카드에 강조.
