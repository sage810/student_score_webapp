# Style Lock — student score webapp

이 파일이 있으면 3단계(톤·색·타이포 도출)를 다시 하지 않고 아래 값을 그대로 재사용한다. 방향을 바꾸고 싶다는 명시적 요청이 있을 때만 갱신한다.

## 배포 방식

- 방식: Google Apps Script HtmlService (Google Sheets 바인딩 스크립트)
- 확인일: 2026-09-18

## 목적·사용자

- 목적: 학생용 수행평가 결과 조회(1회성) + 교사용 담당범위/영역/반별 점수 관리(반복 사용)
- 정보 밀도: 학생 화면 낮음 / 교사 화면 중간~높음
- 격식/친근함: 중간 (학교 공식 도구이지만 학생 화면은 친근한 카드형)
- 사용 빈도: 학생=1회성(콘텐츠형), 교사=반복 사용(도구형)

## 타이포

- 본문/제목 폰트: Pretendard (CDN, 한글 최적화 — Kraken 자체 폰트 대체)
- 기본 크기: 본문 14~15px, 학생 화면 타이틀 22px, 결과 총점 34px
- 최소 글자 크기: 12px (배지·열 제목·라벨 포함)

## 간격·터치 기준

- 간격(padding/margin/gap): 4px 배수만 사용 (2px 반 단계는 허용)
- 터치 영역: 버튼·탭은 44px 이상, 결시 체크박스와 반 칩의 × 버튼은 24px 이상
- 안내 문구(placeholder) 색: `#727589` (`--ink-faint`, 대비 4.5:1 이상)
- 확대(줌) 허용: viewport에 `maximum-scale` 넣지 않음
- 입력칸은 label 또는 `aria-label`을 반드시 연결
- 경고 표시는 이모지 대신 SVG 아이콘 사용

## 레이아웃 구조

- 선택한 틀: 학생 화면 = 가운데 정렬 단일 카드(모바일 우선, JS로 화면1↔2 전환) / 교사 화면 = 상단 바(정보부 업무 관리와 같은 구조: 어두운 띠 24px에 로그아웃만, 그 아래 흰 알약 카드 52px에 브랜드 + 구글 시트 열기, 전체 81px. 어두운 배경은 위 54px까지만이라 카드가 그 아래 경계에 걸쳐 떠 있음) + 단계형 카드 스택
- 교사 화면 메뉴: 상단 바에는 메뉴를 두지 않고, 홈을 포함한 모든 화면에서 좌측 고정 사이드바 사용(홈 화면에서는 "홈"이 선택 상태, 선택 표시는 마지막으로 연 영역 하나만). 사이드바는 넓은 화면에서 흰 배경 248px에 메뉴 이름만 나열(홈 아래 구분선 하나, 선택 항목은 보라 틴트 배경), 1280px 이하는 왼쪽에 떠 있는 164px 도크(흰 카드·20px 모서리, 18px 아이콘 옆에 13px 메뉴 이름, 상단 바 아래 영역의 세로 가운데에 고정해 스크롤 없음, 선택 항목은 보라 배경). 두 경우 모두 선택되지 않은 메뉴는 흐린 글자색(#727589, 대비 4.5:1 유지 — opacity 사용 안 함), 마우스를 올리면 진하게. 본문은 손잡이와 12px 이상 떨어지도록 비키되(닫힌 상태 포함) 640px 이하 휴대폰 폭에서는 비키지 않고 도크가 위에 뜸. 여닫기는 사이드바·도크 오른쪽 가장자리에 붙은 손잡이 탭(보이는 크기 24×56px, 누르는 영역 44px, 닫히면 화면 왼쪽 끝에 남음)
- 선택 이유: 학생은 1회성 폼 입력이라 카드 하나에 집중, 교사는 반복 작업이라 순서가 있는 대시보드 형태가 더 적합
- 화면2(결과) 상세: 상단은 "학기·과목" 알약 배지 + "학급·이름" 카드를 위아래로 분리, 둘 다 텍스트 길이에 맞춰 폭이 줄어드는 가운데 정렬(내용물 hug). 점수 영역은 표 형식(열 제목: 영역/나의 점수/만점, 열 사이 세로 구분선)이고, 그룹 있는 영역은 그룹명을 보라색 소제목으로 표시. 영역마다 3가지 상태를 점수로 구분: 완료(점수/만점 숫자), 미실시(연한 배경 + 이탤릭 + ink-soft, "미실시" 텍스트 — 같은 반에 점수가 있는 학생이 있는데 본인은 없는 경우), 예정(연한 배경 + "예정" 텍스트를 보라 톤으로, 이탤릭 아님 — 같은 반에 아직 아무도 점수가 없는 경우). (2026-10-14 영역 상태 기능 삭제로 "이번 수행" 강조·배지는 없앰) 미실시/예정 모두 opacity로 흐리게 하지 않고 별도 배경(--bg)과 명시적 텍스트 색으로 처리(대비 기준 4.5:1 유지 목적). 총점은 완료된 것만 합산한 "받은점수 / 응시분 만점"(예: 33/36) 형태로 하단 그라디언트 카드에 강조.
